## Key Notes

- `print()` displays information on the screen.
- `return` sends a value back to the caller.
- A function should have one clear responsibility.

## Mini Project

Login Report

The program:
- Takes a username as input.
- Takes the number of failed login attempts.
- Determines whether the login is Suspicious or Normal.
- Returns the result and displays a report.
