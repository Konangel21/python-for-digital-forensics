# Lesson 1 – Variables and Decision Making

## Objective

Learn the basics of Python by building a simple login risk checker.

## Concepts Covered

* Variables
* Data Types (`str` and `int`)
* User Input using `input()`
* Decision Making using `if-else`

## Program Description

The program asks the user to enter:

* Username
* IP Address
* Number of failed login attempts

If the number of failed attempts is 3 or greater, the login is marked as **Suspicious**. Otherwise, it is marked as **Normal**.

## Skills Practiced

* Creating variables
* Taking user input
* Comparing values
* Displaying formatted output

## Future Improvements

* Add error handling
* Repeat until valid input is entered
* Read login records from a file
* Export results to CSV
